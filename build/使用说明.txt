thesis-lint 便携版（Windows x64，版本号见窗口顶部）
==========================================

毕业论文「国标体检」工具 —— 检查 Word 论文参考文献是否符合 GB/T 7714-2025。

【特点】
免安装、无需 Python：解压后双击 thesislint.exe，即可使用黑白双主题图形界面。

【快速上手】
1. 解压本压缩包到任意目录
2. 双击 thesislint.exe，点击选择或把 .docx 论文拖入窗口，自动开始检查
   也可直接把论文拖到 thesislint.exe 图标上
3. 查看文献格式及正文数字引用核对结果，可按“全部 / 错误 / 警告”筛选，再按需生成修正后列表、复制或导出
4. 点击窗口顶部的主题按钮，可切换黑色或白色界面

修正列表与当前检查报告使用同一份内容。若在 Word 中再次修改了论文，
请重新检查后再生成修正列表。导出失败时请换一个保存位置或关闭占用文件的程序。
导出只用于另存报告或修正列表；程序会拦截覆盖 Word 文档或原论文的目标，请另存为 .md 或 .txt。
复制失败时，检查结果仍保留在窗口中；可重试复制，或使用导出功能保存。
文档含正文时，修正列表保留原文献编号，不会自动修正正文引用；粘贴回 Word 后请重新体检。
报告筛选只影响当前显示，复制和导出仍包含完整报告。

【常用参数】
在终端中进入 thesislint.exe 所在目录后运行：
       thesislint.exe 论文.docx                文本格式报告
       thesislint.exe 论文.docx --format md      Markdown 格式报告
       thesislint.exe 论文.docx --format json    JSON 格式报告
       thesislint.exe 论文.docx --strict         有警告时也返回失败码

退出码：0=完成检查且无错误；1=发现错误，或 --strict 模式下有警告；
        2=文件、用法有误或没有可检查的参考文献。

【说明】
- 首次运行启动约需 2~3 秒（单文件自解压），属正常现象
- 程序未做代码签名；若系统提示，请先确认来自官方 Release 并核对 SHA256，
  再自行决定是否运行，不要关闭系统安全防护
- 检查结果仅供参考，最终格式认定以学校要求为准
- 支持从参考文献标题后的段落和 Word 表格提取条目；多列独立编号、格内换行及合并单元格均可处理
- 正文引用只核对参考文献章节前普通段落及表格中的 1–999 数字方括号引用，支持 [1][2]、[1,3-5] 等形式
- 引用核对不覆盖脚注、尾注、文本框、图片、嵌套表格及作者—年份式引用；Word 域只读取已保存的显示结果，不更新域
- “未识别到引用”或“无法可靠映射”等提示表示引用核对未完成，不等于全文没有引用问题；疑似问题请人工确认
- 报告位置是文档块序号，不是 Word 页码或屏幕行号
- 关闭窗口后不再显示后台任务结果；已启动的计算自行结束，不会改写原论文
- “规则依据”会打开 GB/T 7714-2025 国家标准官方信息页；最终格式仍以学校要求为准
