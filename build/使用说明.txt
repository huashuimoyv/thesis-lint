thesis-lint 便携版（Windows x64，版本号见窗口顶部）
==========================================

毕业论文「国标体检」工具 —— 检查 Word 论文参考文献是否符合 GB/T 7714-2025。

【特点】
免安装、无需 Python：解压后双击 thesislint.exe，即可使用黑白双主题图形界面。

【快速上手】
1. 解压本压缩包到任意目录
2. 双击 thesislint.exe，点击选择或把 .docx 论文拖入窗口，自动开始检查
   也可直接把论文拖到 thesislint.exe 图标上
3. 查看报告，按需生成修正后列表，复制或导出；原论文不会被修改
4. 点击窗口顶部的主题按钮，可切换黑色或白色界面

修正列表与当前检查报告使用同一份内容。若在 Word 中再次修改了论文，
请重新检查后再生成修正列表。导出失败时请换一个保存位置或关闭占用文件的程序。

【常用参数】
在终端中进入 thesislint.exe 所在目录后运行：
       thesislint.exe 论文.docx                文本格式报告
       thesislint.exe 论文.docx --format md      Markdown 格式报告
       thesislint.exe 论文.docx --format json    JSON 格式报告
       thesislint.exe 论文.docx --strict         有警告时也返回失败码

【说明】
- 首次运行启动约需 2~3 秒（单文件自解压），属正常现象
- 程序未做代码签名；若系统提示，请先确认来自官方 Release 并核对 SHA256，
  再自行决定是否运行，不要关闭系统安全防护
- 检查结果仅供参考，最终格式认定以学校要求为准
